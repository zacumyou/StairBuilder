# Stair Builder
## 여기에 계단 하나 있으면 좋겠는데!

언덕 위 공원으로 올라가는 계단, 건물 옆 좁은 통로, 산책로를 잇는 나무 데크까지.

**시작점과 끝점을 찍고, 높이와 폭을 맞춰보세요.** 원하는 자리에 계단을 만들 수 있습니다. 중간에 점을 추가해 방향을 꺾거나, 계단 대신 경사로로 구성할 수도 있습니다.

## 설치

**필수 에셋:** [CS KR Stair Builder Dependency](https://mods.paradoxplaza.com/mods/166122/Windows)를 함께 구독하고 같은 플레이셋에서 활성화해주세요. 에셋 팩만으로는 계단 제작 도구가 나타나지 않습니다.

**지원 언어:** 한국어, 영어. [Gizmo XYZ](https://mods.paradoxplaza.com/mods/159946/Windows)는 선택 사항입니다.

## 주요 기능

- **6가지 계단 스타일** — 기본형, 모던형, 옛날형, 터널형, 철재형, 나무 데크
- **난간과 색상 선택** — 계단부와 난간부를 따로 꾸밀 수 있습니다.
- **드래그로 폭 조절** — 옆선을 잡고 0.1m 단위로 넓히거나 줄여보세요.
- **점 추가와 높이 조절** — 꺾이는 계단과 수평 통로도 만들 수 있습니다.
- **스냅과 가이드라인** — 표면에 붙이거나, 방향과 점의 위치를 맞출 때 사용합니다.
- **복사와 템플릿** — 마음에 드는 계단은 다시 쓸 수 있도록 저장! 템플릿은 최대 50개까지 지원합니다.

## 사용법

### 1. 계단부터 하나 만들어볼까요?

1. 게임 우측 상단의 **Stair Builder 아이콘**을 누릅니다.
2. **새 계단**을 선택하고, 시작점과 끝점을 차례로 찍어주세요.
3. **배치** 탭에서 높이와 폭을 조절합니다. 시작점과 끝점의 높이가 달라야 올라가는 계단이 됩니다.
4. 미리보기가 마음에 들면 **만들기**를 누르면 끝!

높이는 숫자를 직접 입력하거나 `− / +` 버튼으로 바꿀 수 있습니다. **지면 기준 상대 높이** 옆의 동그라미 안 `0` 아이콘을 누르면, 선택한 점의 높이를 그 지면에 맞춥니다.

이미 만든 계단을 바꾸고 싶다면 계단을 클릭한 뒤 **편집**을 선택하세요. 수정한 내용은 **변경 적용**으로 확정합니다.

### 2. 곧은 계단만 만들 수 있나요?

**점 추가**를 누르고 다음 위치를 찍으면 구간이 이어집니다. 중간에서 방향을 꺾거나, 잠깐 평평하게 이어지는 통로를 만들어보세요. **이전 점과 높이 맞춤**을 사용하면 같은 높이로 잇기 편합니다.

추가한 점은 **이전 끝점의 절대 높이를 유지하며, 스냅은 꺼진 상태로 시작합니다.** 지면에 갑자기 붙지 않도록 한 동작입니다. 필요한 만큼 높이를 조절하고, 스냅이 필요하면 아래 아이콘을 다시 켜주세요.

계단 대신 완만한 통로가 필요하다면 **배치 → 경사로**를 선택합니다. 너무 가파르다는 안내가 나오면 길이를 늘리거나 높이 차이를 줄여주세요.

### 3. 분위기에 맞게 스타일 바꾸기

**외형** 탭에서 색깔 있는 스타일 아이콘을 눌러보세요. 새로 만드는 중에도, 기존 계단을 편집하는 중에도 바꿀 수 있습니다.

- **기본형** — 무난하게 쓰기 좋은 계단
- **모던형** — 깔끔한 공원이나 새 건물 주변
- **옛날형** — 오래된 골목이나 생활감 있는 공간
- **터널형** — 지붕이 있는 계단 통로
- **철재형** — 산업 시설이나 외부 철제 계단
- **나무 데크** — 등산로, 산책로, 자연 속 쉼터

**난간 구성**도 따로 고를 수 있습니다. 스타일에 맞는 기본 난간을 쓰거나, 다른 난간·경계석으로 바꿔보세요. 난간 없이 만드는 것도 가능합니다.

색은 **계단부 색상 / 난간부 색상**에서 각각 조절합니다. 원래 모습으로 돌아가고 싶다면 **기본색**을 선택하세요. 아래를 기둥으로 받칠지, 지면까지 채울지도 **하부 구성**에서 정할 수 있습니다.

### 4. 폭은 직접 보면서 조절하세요

1. 미리보기 또는 편집 상태에서 **계단의 양옆 선에 마우스를 올립니다.**
2. 폭 조절 아이콘이 나타나면 잡고 좌우로 드래그하세요.
3. 원하는 폭에서 놓고 **만들기** 또는 **변경 적용**을 누릅니다.

**잡은 쪽을 넓히거나 줄이고, 반대쪽 경계는 유지합니다.** 폭은 **1~8m 범위에서 0.1m 단위**로 맞춰집니다. 패널의 폭 버튼으로 자주 쓰는 크기를 바로 선택해도 됩니다.

드래그하는 동안에는 가벼운 윤곽선으로 폭을 보여줍니다. 손을 놓으면 바뀐 폭의 계단 모양을 확인할 수 있습니다.

### 5. 스냅, 필요한 것만 켜두세요

스냅은 위치를 가까운 표면이나 기준선에 맞춰주는 기능입니다. **패널 아래, 만들기 버튼 위의 아이콘**으로 각각 켜고 끕니다. 아이콘에 마우스를 올리면 이름도 확인할 수 있습니다.

- **물체 표면 / 도로 표면:** 해당 표면을 기준으로 점을 배치합니다.
- **방향 스냅:** 세 번째 점부터 이전 구간의 연장선이나 직각 방향에 맞춥니다.
- **점 정렬 스냅:** 기존 점을 지나는 정렬선과 교차점에 맞춥니다.
- **직각으로 꺾기:** 다음 구간을 직각 방향으로 잡을 때 사용합니다.
- **가이드라인 표시:** 정렬선을 보여줍니다. 선을 켜는 것과 스냅을 켜는 것은 별개입니다.

옆의 `− / +`는 **스냅이 잡히는 범위**를 조절합니다. 자꾸 원하지 않는 곳에 붙는다면 범위를 줄여보세요. 폭을 0.1m 단위로 맞추는 기능과는 다른 설정입니다.

새 계단은 표면·방향·점 정렬 스냅이 켜진 상태로 시작합니다. 자유롭게 배치하고 싶을 때는 필요한 아이콘을 꺼주세요.

### 6. 잘 만든 계단, 다음에도 쓰고 싶다면?

계단 미리보기나 완성된 계단 위에 뜨는 **템플릿으로 저장 아이콘**을 누르세요. 이름을 정하고 저장하면 됩니다. 이름을 비워두어도 자동으로 이름을 붙여 저장합니다.

다시 사용할 때는 패널의 **템플릿**을 열고 원하는 이름을 누릅니다. **현재 만들거나 편집하던 계단은 완료하고, 선택한 템플릿으로 새 계단을 배치하는 단계로 넘어갑니다.** 아직 점을 배치 중이거나 완료할 수 없는 상태라면 현재 작업을 먼저 마쳐주세요.

배치할 위치를 고르면서 필요하면 **왼쪽 90° / 오른쪽 90°**로 돌려보세요. 원하는 위치를 클릭하고 **만들기**를 누르면 끝!

템플릿은 최대 **50개**까지 저장할 수 있으며, **이름 검색·이름 변경·현재 계단으로 덮어쓰기·삭제**도 지원합니다. 여기서 덮어쓰기는 저장된 템플릿의 내용을 바꾸는 기능입니다. 템플릿을 삭제해도 이미 도시에 배치한 계단은 지워지지 않습니다.

### 7. 복사하거나, 통째로 옮기거나

완성된 계단을 선택하거나 편집하면 계단 위에 작업 아이콘이 나타납니다. 아이콘에 마우스를 올리면 기능 이름을 볼 수 있습니다.

- **복사:** 같은 계단을 하나 더 배치합니다. 위치와 방향을 정한 뒤 **만들기**로 확정하세요. 신규 제작 중에는 표시되지 않습니다.
- **옮기기:** 계단 전체를 다른 위치로 옮깁니다. 높이는 유지되며, 위치를 찍고 **변경 적용**을 누르면 됩니다.
- **템플릿으로 저장:** 지금 모양을 나중에도 꺼내 쓸 수 있도록 저장합니다.

**Gizmo XYZ**를 함께 사용한다면, 완성된 계단을 선택한 상태에서 **Ctrl+T로 이동, Ctrl+D로 복제**할 수 있습니다. 편집 버튼을 먼저 누를 필요는 없습니다. 기존 계단을 편집하는 중에도 사용할 수 있으며, 계단 전체의 위치를 조절하는 기능으로 회전은 지원하지 않습니다.

Gizmo XYZ 없이도 Stair Builder의 기본 배치·복사·옮기기는 사용할 수 있습니다.

## 사용 전 참고해주세요

- 점 사이가 너무 좁거나 높이 차이가 크면 계단을 만들 수 없을 수 있습니다. 패널의 안내에 따라 길이와 높이를 조절해주세요.
- 보행 연결을 만들려면 양 끝의 보도·보행로 연결 상태도 확인해야 합니다. 계단이 보인다고 시민이 반드시 이용하는 것은 아닙니다.
- 먼 계단은 간략하게 표시하고, 가까워지면 상세 모델을 준비합니다. 복잡한 계단을 한꺼번에 많이 생성할 때는 잠시 지연될 수 있습니다.

템플릿은 도시 세이브와 별도로 PC에 저장됩니다. 다른 PC로 옮기거나 백업할 때는 아래 파일도 함께 보관해주세요. 계단을 사용하는 도시에서는 코드 모드와 필수 에셋을 함께 활성화해주세요.

`%USERPROFILE%\AppData\LocalLow\Colossal Order\Cities Skylines II\ModsData\StairBuilder\templates.json`

## 문제 제보

이상한 모양이 나오거나 조작이 잘되지 않는다면, **사용한 계단 스타일·난간·폭과 문제가 생긴 순서**를 함께 알려주세요. 화면 캡처도 있으면 확인하는 데 도움이 됩니다.
