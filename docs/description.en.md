# Stair Builder

## This spot could use a staircase!

A path up to a hilltop park, a narrow passage beside a building, or a timber deck along a walking trail.

**Pick a start and an end, then adjust the height and width.** Add more points to turn a corner, or switch to a ramp when that suits the space better.

## Installation

**Required assets:** Subscribe to [CS KR Stair Builder Dependency](https://mods.paradoxplaza.com/mods/166122/Windows) and enable it in the same playset as Stair Builder. The asset pack alone does not provide the building tool.

**Languages:** English and Korean. [Gizmo XYZ](https://mods.paradoxplaza.com/mods/159946/Windows) is optional.

## Features

- **Six styles** — Classic, Modern, Weathered, Tunnel, Steel, and Timber Deck.
- **Railings and colors** — Choose the staircase and railing finishes separately.
- **Drag to resize** — Grab a side edge and adjust the width in 0.1 m steps.
- **Extra points and height controls** — Build turns and level sections along the way.
- **Snapping and guides** — Place points on surfaces or align them with directions and other points.
- **Copy and templates** — Keep a design for later, with room for up to 50 templates.

## How to use

### 1. Let's build a staircase

1. Click the **Stair Builder icon** at the top right of the screen.
2. Choose **New stair**, then click the start and end positions.
3. Adjust the height and width in the **Layout** tab. Give the two ends different heights to make stairs that climb.
4. Happy with the preview? Click **Create**, and you're done!

Enter a height directly or use the `− / +` buttons. The **circled zero icon** beside the ground-relative height sets the selected point to ground level.

To change an existing staircase, select it and choose **Edit**. Finish with **Apply changes**.

### 2. Take a turn

Click **Add point**, then choose the next position to extend the staircase. Turn a corner or add a level walkway. **Match previous point height** helps keep adjacent points at the same elevation.

An added point starts at the **previous endpoint's absolute height, with snapping switched off**. It won't suddenly drop to the ground. Adjust its height as needed, and turn snapping back on using the icons below.

For a sloped walkway, choose **Layout → Ramp**. If the slope is too steep, increase the length or reduce the height difference.

### 3. Find a style that fits

Open the **Appearance** tab and choose a colored style icon. You can change styles while creating a staircase or editing an existing one.

- **Classic** — Everyday stairs
- **Modern** — Neat parks and newer buildings
- **Weathered** — Older streets and lived-in spaces
- **Tunnel** — Covered stairways
- **Steel** — Industrial sites and exterior metal stairs
- **Timber Deck** — Hiking trails, walking paths, and woodland rest areas

Choose the **railing** separately. Keep the style's default, try another railing or curb, or leave the sides open.

Adjust the **staircase and railing colors** independently. Choose the default color to restore the original finish. The base options also let you choose between supports and a solid base extending to the ground.

### 4. Adjust the width on the preview

1. Hover over either **side edge** while creating or editing a staircase.
2. When the width handle appears, drag it sideways.
3. Release at the width you want, then click **Create** or **Apply changes**.

**The edge you grab moves; the opposite edge stays in place.** Width ranges from **1 to 8 m in 0.1 m steps**. The panel also has preset width buttons.

While dragging, a lightweight outline shows the new width. Release the handle to see the updated staircase.

### 5. Use the snapping you need

Snapping helps place points on nearby surfaces or alignment lines. Toggle each option using the **icons above the Create button**. Hover over an icon to see its name.

- **Object / road surfaces:** Place points using those surfaces.
- **Direction snapping:** From the third point onward, align with the previous segment or a right angle.
- **Point alignment:** Snap to alignment lines through existing points and their intersections.
- **Right-angle turns:** Set the next segment at a right angle.
- **Guide lines:** Show alignment guides. Showing a guide and enabling snapping are separate options.

The nearby `− / +` buttons adjust the **snap detection range**. Reduce it if points keep snapping somewhere you don't want. This is separate from the 0.1 m width increments.

New staircases start with surface, direction, and point-alignment snapping enabled. Switch off whichever options you don't need.

### 6. Save a design for next time

Click the floating **Save as template icon** above the preview or a completed staircase. Give it a name and save. Leave the name blank to use an automatically generated name.

To reuse it, open **Templates** in the panel and click a template name. **Your current valid staircase is completed first, then you begin placing a new staircase from the selected template.** If you're still placing a point or the current staircase cannot be completed, finish that step first.

Choose a position and use **Rotate left 90° / Rotate right 90°** if needed. Click to place it, then **Create** to finish!

Store up to **50 templates**, with **search, rename, overwrite with the current design, and delete** controls. Overwrite updates the saved template itself. Deleting a template does not remove staircases already placed in your city.

### 7. Make a copy, or move the whole staircase

Select or edit a completed staircase to show its floating action icons. Hover over each icon to see what it does.

- **Copy:** Place another staircase with the same design. Choose its position and orientation, then click **Create**. This icon is hidden while creating a brand-new staircase.
- **Move:** Relocate the whole staircase while keeping its height. Choose the new position, then click **Apply changes**.
- **Save as template:** Keep the current design for later.

With **Gizmo XYZ**, select a completed staircase and press **Ctrl+T to move** or **Ctrl+D to duplicate**. You don't need to enter editing mode first. These shortcuts also work while editing an existing staircase. The integration moves the whole staircase; rotation is not supported.

Stair Builder's own placement, copy, and move tools work without Gizmo XYZ.

## Before you build

- Points that are too close together or too far apart in height may prevent a valid staircase. Follow the panel's guidance to adjust the length and height.
- For pedestrian access, check the sidewalk or path connections at both ends. A visible staircase alone does not guarantee citizens will use it.
- Distant staircases use simpler models, with detailed models prepared as you approach. Creating many complex staircases at once may cause a short delay.

Templates are stored on your PC separately from city saves. Include this file when backing up templates or moving them to another PC. Keep the code mod and required assets enabled for cities using these staircases.

`%USERPROFILE%\AppData\LocalLow\Colossal Order\Cities Skylines II\ModsData\StairBuilder\templates.json`
