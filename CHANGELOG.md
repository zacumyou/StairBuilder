# Changelog

## 0.9.14 — 2026-11-03

Initial public release.

- Six stair styles, ramps, separate railings and colors, and support options.
- Extra route points, surface/alignment snapping, and 0.1 m width dragging.
- Floating copy, move, and template-save actions; up to 50 reusable templates.
- Selecting a template completes the current valid stair before starting a new placement.
- Optional Gizmo XYZ translation/duplication from a selected completed staircase.
- Shared geometry, distance-based simplified models, distributed model preparation, and lightweight drag outlines.
- Fixed floating UI positioning that used unsupported mixed-unit Gameface expressions.

Validation: C#/Burst and UI builds passed. Recent interaction changes and subscription-only asset loading still require gameplay verification.
